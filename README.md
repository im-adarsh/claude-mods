# claude-mods

A collection of small Claude Code mods and themes.

| Folder | What it is |
|---|---|
| [`goland-skin`](goland-skin) | JetBrains GoLand Darcula colors for Claude Code, plus a matching Warp terminal theme. `/goland on\|off\|status` switches it live |
| [`diagram-preview`](diagram-preview) | Preview Mermaid and Excalidraw diagrams as Artifacts, from pasted source or a file |
